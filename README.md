# Controle de Validade - Logística

## 🎯 Objetivo
Sistema desenvolvido para controle e acompanhamento da validade de materiais, auxiliando na tomada de decisão operacional e redução de perdas.

## 💡 Regra de Negócio
Os materiais são classificados em:

- ✅ Bom
- ⚠️ Abaixo de 30% da validade
- ❌ Vencido

Quando o material está abaixo de 30%, pode ser gerada uma **carta de troca**.

## ✅ Status Atual
- MVP funcional em HTML
- Interface de visualização
- Lógica inicial de classificação

## 🚫 Limitações atuais
- Não possui banco de dados
- Não possui histórico
- Não possui indicadores automáticos

## 🔮 Próximas evoluções
- Integração com banco de dados
- Criação de indicadores (dashboard)
- Histórico de movimentações
- API com Node.js
- Automações futuras
